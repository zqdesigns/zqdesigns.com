Lesson Draft Staging

Lesson Draft Staging is a private tool that connects my content workstation to one Google account set aside for drafts. It saves CircuitBread lesson drafts there as Google Docs so I can review and edit them, then reads my edits back when a draft needs another revision.

Who uses it

Only me. It isn't offered to the public, there's no sign-up, and it connects to a single Google account I created for this work. That account has no access to my business accounts or anyone else's.

How it works

A dedicated computer runs the drafting workflow for CircuitBread lessons, using AI assistants (OpenAI's ChatGPT and Anthropic's Claude) to draft material and check it against our content standards. When a draft is ready for me, Lesson Draft Staging saves it, with any supporting files, to Google Drive in the staging account. I review and edit it there, the app picks up my changes for the next revision, and I move finished work into the business's shared drive myself.

What it can access in Google

Lesson Draft Staging only works with files it creates. It can't see anything else in the account.
